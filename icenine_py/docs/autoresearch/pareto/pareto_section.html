Cost against accuracy, all methods

You asked for the frontier of cost against accuracy for every method tried so far. Each point below is one method run on one sample. Left is cheaper. Down is more accurate. A method is on the frontier when no other method on the same sample is both cheaper and more accurate. A line joins those methods, and each has a ring.

  • Cost is the number of evaluations of the whole run divided by the number of voxels. An evaluation is one call of the cost function for one voxel and one orientation. The axis is logarithmic.
  • Accuracy is the share of voxels that end more than 1 degree from the true orientation, after crystal symmetry. All samples are simulated, so the truth is known.
  • One panel per sample. The methods were run on six different samples. Two points can be compared only inside one panel.

Terms. BFS is the breadth-first search: a voxel starts its local optimization from a finished neighbour, and a seed is a voxel that needs a global search. Indexed seeds means the seed comes from ray indexing, with the grid search only as a fallback. Stock is the local optimization the search uses by default. CMA is the other local optimization in the code, with a first step of 0.05 degrees; "library CMA" is the same one switched on by the keys the code already has. Paint grains gives each voxel the orientation of a grain already found, with one evaluation. A boundary pass comes after a run: each voxel at a grain boundary gets one short try from each neighbouring grain's orientation.

What the frontiers say

  • Global search. Ray indexing with a local optimization on the best 2 candidates is on the frontier on the pilot's 69 voxels and on the holdout. On the 200 easy voxels the first candidate alone is already right. On the pilot's 69 voxels the best-2 rule needs about 170 times fewer evaluations than the grid search (1,926 against 332,380), with 0 against 4 wrong. The two intervals overlap, so read that as "not worse".
  • Whole run, grains with gradients. The best trade so far is the BFS with indexed seeds, the CMA local optimization and one boundary pass: 1,579 evaluations per voxel and 74 wrong (0.30%). The base run needs 4,817 and leaves 203 wrong (0.83%). That is about 3 times fewer evaluations and fewer wrong voxels.
  • The boundary pass moves a run down. In all seven runs that have it, the run with the pass has fewer wrong voxels than the same run without it. One pass costs about 125 to 150 evaluations per voxel.
  • Whole run, one orientation per grain. Painting is the cheapest by far, at 54 to 78 evaluations per voxel. This holds only when each grain has a single orientation, which real grains do not.
  • What is left to cut. Of the 1,430 evaluations per voxel in the cheapest run on the gradient sample, 1,051 come from 76 seeds where indexing failed and the grid search ran. Step 6 (running) tests cheaper steps for those seeds. Its points will be added here.
  • No whole-layer run uses a grid search for every seed. On the pilot that run needs 9 times the evaluations of the run with indexed seeds. So the two whole-layer panels start from a baseline that is already reduced.

Limits of these plots

  • One run per point. A difference of a few voxels, such as 57 against 56, is inside the intervals. The table below gives a 95% interval for each share.
  • Evaluations, not time. The cost axis counts calls of the cost function. Pairing the spots (once, 17 s) and the indexing vote (about 0.17 s per voxel) are not evaluations and are not on the axis. Wall time is not shown.
  • Not drawn. Two other keep rules of the boundary pass cost the same as the drawn one and leave more voxels wrong. They are in the table.
  • Left out, because cost and accuracy are not both known for a complete map:
    • the stop rules of AR0 (the page gives only the share of evaluations saved, at most 1.26%);
    • the skip and stop rules of steps 3, 4 and 5 (saved evaluations only);
    • run K of step 5 (stopped by its time cap with no finished map);
    • three BFS variants of AR0 on the pilot (wrong counts, but no evaluation total);
    • splits of a run by voxel group or by gradient level (no evaluations per group).
