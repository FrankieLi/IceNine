Cost against quality

Vertical axis: voxels more than 0.1 deg from the ground truth, as a percentage of all voxels in the set, pooled over grains (not a per-grain average). Horizontal axis: objective evaluations per voxel. Grey: reference points, set = all 19,013 painted voxels of grad. Coloured: GO2 arms, set = the 853 voxels of the 20 benchmark grains (G20) that have an AR3 C record (start 84 of 853, C 18 of 853).

Unit. One objective evaluation is one call of the objective being fitted. In a grain fit that call scores every voxel of the grain once, so N grain evaluations count as N per voxel. In a per-voxel fit it is one strict-cost call for one voxel. Chained stages add up. Log scale; 0 = no fit.
